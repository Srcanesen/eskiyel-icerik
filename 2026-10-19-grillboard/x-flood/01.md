Your AI agent asks a dozen questions before it builds. By question 7 you have forgotten what you said at question 2.

GrillBoard puts the whole interview on a live board in your browser. The agent asks, the options appear as cards, you click. Every settled answer becomes a node in a decision tree. For layout questions the agent draws a small sketch of each option, so you choose by looking. When every branch is settled and you confirm, it writes spec.md.

It is a skill for Claude Code (and other agents that load SKILL.md). One HTML file, one Python file, no dependencies, MIT.
